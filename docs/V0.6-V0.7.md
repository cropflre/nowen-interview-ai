# V0.6–V0.7 操作与验收

## V0.6 · 日历时区

- `APP_TIME_ZONE` 使用 IANA 名称，默认 `Asia/Shanghai`；例如 `APP_TIME_ZONE=America/Los_Angeles npm start`。无效时区会报错，不会静默替换成 UTC。
- 所有写入数据库的 `created_at`、`finished_at`、`last_review_at` 等瞬时时间仍为 UTC ISO 8601；只在「今日」/到期/延迟复测判定时用 `calendarDay()`。
- `server/calendar.mjs` 通过 IANA 日历确定当天 UTC 起止时间，支持夏令时造成的 23/25 小时日。每日任务按 `[start,end)` 时间戳查两座世界通关、复习和面试记录。
- 改动前的 `daily:YYYY-MM-DD:*` 奖励键使用 UTC 日期；升级后同名日期键解释为配置的本地日历。原账本不重写，不会删经验，但跨旧/新日界线的首次升级当天可能出现历史归属差异。升级前先备份，尽量不要频繁改变时区。
- 间隔复习的 `due_on` 是日历日期字符串，不是时间戳。旧排程原样保留，日后根据配置日历判断到期；复习结果仍是**自评覆盖**而非客观正确率。
- 验收：上海午夜前后、美国 DST 两种日长、世界地图与复习到期一致、当前本地自然日奖励幂等。真正等待一个日界线的 E2E 尚未执行。

## 数据备份（可以在服务运行时执行）

默认数据库为 `data/interview.db`；建议先保存备份，再升级代码：

```bash
npm run backup
# 或指定源数据库和输出路径：
npm run backup -- /absolute/path/interview.db /absolute/path/backup.sqlite
```

备份使用 SQLite `VACUUM INTO` 产生一致性快照，会包含已提交的 WAL 数据（而不是仅复制 `.db` 主文件），输出 `.sqlite` + 同名 `.sqlite.json` SHA-256 清单。目标文件存在则拒绝覆盖；默认输出在被 Git 忽略的 `backups/` 下。请将备份及清单同时离线保存并注意其中可能包含个人学习记录。

## 离线恢复（破坏性操作）

**必须先退出网站和 Node API，确认 SQLite 已完成关闭和 WAL checkpoint。** 以下命令会替换目标数据库，不能在应用运行中执行：

```bash
npm run restore -- /absolute/path/backup.sqlite /absolute/path/interview.db --confirm
# 若恢复到默认 data/interview.db，可省略第二个文件名：
npm run restore -- /absolute/path/backup.sqlite --confirm
```

恢复前检查清单、文件大小、SHA-256、`PRAGMA integrity_check` 和必要表。若目标旁存在 `-wal` 或 `-shm`，为防止丢失未 checkpoint 的事务直接拒绝。恢复时先复制到同目录临时文件再次校验，把原库改名保留为 `.pre-restore-...sqlite`，再原子替换。恢复前原库副本不自动删除。**不要手动删除活跃数据库的 WAL 来绕过保护。** 若不确定数据库是否已正确关闭，保留原文件并先定位占用进程。

## V0.7 · React 框架群岛

解锁要求：完成 JavaScript 森林最终 BOSS。世界地图和顶部导航均能进入群岛；未通关可查看锁定原因。五关每关三题，答对至少两题解锁下一关：

1. 状态港湾：源状态、派生数据、共享状态。
2. 副作用礁石：Effect 使用边界、清理和请求竞态。
3. 协调航道：key 身份、列表重排和渲染/提交。
4. 性能灯塔：Profiler、useMemo 与虚拟列表。
5. BOSS · 组件架构守卫者：综合状态、请求时序与列表身份。

群岛关卡使用新增的 `framework_progress`、`framework_attempts`、`framework_answers` 表，不迁移/覆盖旧森林存档；`game_players` 和 `game_rewards` 是共享账本，重玩不重复领取首通与首次满分奖励。错题会写入原有 `review_items`，第三颗记忆星仍依赖对应知识点的成功跨天自评。与森林一样，选项判分不是 AI 语义评分。

前四关首通 120 XP / 首次满分 30 XP，BOSS 首通 350 XP / 首次满分 70 XP。完整满分章节总计 1020 XP；重玩可计入当日训练，但不会再领取首次奖励。每日任务的冒险进度同时统计两个世界。

## 验证与边界

```bash
npm install
npm test
npm run build
npx playwright install chromium
npm run test:e2e
```

CI 为每次 `main` 推送自动执行上述测试和构建。浏览器覆盖两世界锁定与通关、途中刷新恢复、重复结算、每日 XP、代码工坊、记忆训练；仍未覆盖所有浏览器/手机型号及真实跨日等待。当前单人本地模式无认证，不可直接开放公网。尚无 AI 动态问答或安全的用户代码执行沙箱。
