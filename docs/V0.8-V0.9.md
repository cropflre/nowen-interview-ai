# V0.8–V0.9 · AI 模拟面试与本机账户隔离

> 当前是 **本机原型**，不是可公网部署的多租户服务，也不是对实际面试结果的预测。`AUTH_MODE=local` 是默认值；更新代码不会自动创建账户、迁移或删除原有 `data/interview.db`。

## V0.8：模型追问与有依据的复盘

保留现有 15 道人工编写的核心题与两轮固定追问。顶部新增「🤖 AI 面试」：服务端连接兼容 OpenAI `chat/completions` 的接口；用户在创建每场 AI 面试前勾选同意，将题目和回答发送给自己配置的模型供应方；模型根据刚才的答案生成下一轮追问。模型超时或服务错误时，保留已存储的答案，使用原先的人工追问。全部回答或提前结束后尝试生成定性复盘，并标注未能得到 AI 复盘的情况。

**AI 复盘不是客观打分。** 现有关键词覆盖报告仍只是关键词命中；模型总结可能出错，要求用户核对技术论点。没有启用模型时，全部规则模式与游戏/记忆功能可用。模型不可用时的降级和模拟模型的实际回答流程均纳入自动化测试；没有使用真实付费模型进行在线质量基准测试。

### 配置模型服务

在启动服务的终端配置环境变量，不要把密钥写入前端代码、提交到 Git 或通过 UI 日志打印。例如 Linux/macOS：

```bash
export AI_API_URL='https://YOUR_PROVIDER/v1/chat/completions'
export AI_MODEL='YOUR_MODEL_ID'
export AI_API_KEY='YOUR_SECRET'
npm run dev
```

Windows PowerShell：

```powershell
$env:AI_API_URL = 'https://YOUR_PROVIDER/v1/chat/completions'
$env:AI_MODEL = 'YOUR_MODEL_ID'
$env:AI_API_KEY = 'YOUR_SECRET'
npm run dev
```

填写实际供应方的完整聊天补全 URL，而不是网页地址。对支持免密的本机模型，可不设置 `AI_API_KEY`；**仅在本机回环地址**明确设置 `AI_ALLOW_HTTP_LOCAL=1` 后，允许 `http://127.0.0.1:...` 或 `http://localhost:...`。其余连接必须使用 HTTPS。请求最长等待 20 秒，返回有大小限制。模型服务的收费、保留政策和可用性由你使用的供应方决定。

## V0.9：本机账户和独立存档

默认启动方式不变：

```bash
npm install
npm run dev
```

`data/interview.db` 原样继续使用，原有游戏进度、每日任务、记忆中心与规则面试不会被自动迁移。

如果需要在**同一台机器**上按用户区分记录，先备份数据库，再在本机启用：

Linux/macOS：

```bash
export AUTH_MODE=accounts
npm run dev
```

PowerShell：

```powershell
$env:AUTH_MODE = 'accounts'
npm run dev
```

首次从本机浏览器访问，创建首个账户；密码至少 12 个字符。账户目录为 `DATA_DIR/auth.sqlite`（存储凭据哈希及会话）与 `DATA_DIR/users/<user-id>/interview.db`（各自的面试、游戏、XP 和记忆记录）。每个账户所有原有 API 路由都在**对应数据库文件**执行；会话令牌只以哈希存库，退出登录会注销会话。网页仅在通过鉴权后加载游戏组件。账户创建、双账户隔离、冒用其他账号挑战 ID、跨站修改与注销均有自动化测试。

创建**后续**账户必须由同机管理员执行（不可任意网页自助注册）：

```bash
npm run account -- create bob
```

命令优先在交互终端隐藏输入密码；无交互终端可在**受信任的本机**通过 `NOWEN_NEW_USER_PASSWORD` 环境变量传入，但要避免泄露进 shell 历史和日志。账户模式刻意拒绝监听非本机地址；它没有 HTTPS 终结、邮箱找回、密码重设、审计日志、跨机器同步和公网安全审计，**不要直接开放公网或局域网**。

### 从旧单人存档迁移（非破坏式）

**先停止应用和 API，确认所有 SQLite WAL/SHM 已关闭或完成检查点，备份旧库。** 迁移仅允许写入一个**尚未创建玩家数据库**的账户，绝不覆盖已有存档，也不会删除原始 `data/interview.db`。推荐步骤：

1. 保留 `AUTH_MODE=local` 的数据，停止程序。运行 `npm run backup` 并将产生的 `.sqlite` 与 `.sqlite.json` 放到安全位置。
2. 在 `AUTH_MODE=accounts` 下启动一次，创建首个账户（若已经创建，继续使用现有账户即可）。要迁移旧进度，请**另通过 CLI 创建一个尚未登录的新账户**，不要先访问该新账户的世界地图，否则会生成目标数据库，迁移会安全拒绝覆盖。
3. 停止程序，在项目根目录执行：

   ```bash
   npm run account -- create oldplayer
   npm run account -- migrate oldplayer --confirm
   ```

   已创建 `oldplayer` 时只执行第二条。也可以提供旧库路径：`npm run account -- migrate oldplayer /absolute/path/interview.db --confirm`。程序会先生成一致性备份并校验 SHA-256 与 SQLite 完整性，再恢复到该账户目录；新路径和源库保留信息会打印出来。
4. 重启 `AUTH_MODE=accounts`，登录迁移后的账户验证完整进度。如果目标已有存档，**不要强行覆盖**；先另建空账户或人工核查目标与备份。

请勿在应用运行时直接复制单独的 `.db` 文件而忽略 WAL；不要自行将 `auth.sqlite` 替换成用户存档文件。V0.6 `npm run backup -- <database-file> <snapshot.sqlite>` 仅支持玩家数据库，**备份账户模式需分别备份各玩家的数据库，并在完全停机后安全保存 `auth.sqlite` 与整个 `users/` 目录**；敏感备份应妥善加密保管。

### 扩充知识卡

V0.9 另提供 12 条可选的进阶**记忆卡**，涵盖 TS 校验、React 竞态与身份、INP、XSS、SSE、Worker、构建部署及 AI 安全。添加到默认旧本地库：

```bash
npm run bank:seed
```

添加到指定用户库：

```bash
npm run bank:seed -- /absolute/path/to/data/users/USER_ID/interview.db
```

要求目标数据库已经存在；稳定 ID 和 `INSERT OR IGNORE` 让重复导入不会覆盖既有学习日志。**这 12 条是记忆训练卡，不是新增加了 12 场 AI 面试题，也不包含未经审核的自动代码判分。** 旧版可选的 110 道题导入脚本继续保留。
